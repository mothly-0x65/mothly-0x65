# Eric Jerman

I design hardware for AI. My main interest is chip design for AI acceleration and neuromorphic computing: architectures that compute efficiently close to where the data lives.

- MSc Computer and Embedded Systems Engineering at TU Delft
- Member of Technical Staff at Forgis in Zurich, building AI that turns industrial electrical schematics into PLC projects
- Previously hardware engineer at Delft Hyperloop, designing PCBs and writing embedded Rust firmware

**Interests:** digital and custom IC design, hardware accelerators, neuromorphic architectures, FPGAs, embedded systems

**Tools:** SystemVerilog, VHDL, Cadence, Xilinx Vivado and Vitis HLS, Altium Designer, Rust, Python, C/C++, Julia

## Projects

- [IMU-DH10](https://github.com/mothly-0x65/IMU-DH10): firmware for a custom IMU board (STM32H7, AD7768 24-bit ADC, UDP over Ethernet) in async embedded Rust on Embassy
- [probabilistic-models-eric](https://github.com/mothly-0x65/probabilistic-models-eric): custom Metropolis-Hastings inference in Gen.jl for a CPU cache model and a genetic oscillator
